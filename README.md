# Ralphs-world
This is a website that features Jane's golden retriever, Ralph.
I created this website to introduce my golden retriever, Ralph, and share some of his favorite things. It includes a home page and a favorites page with photos of boat days and coffee dates.

I wanted to expand my original website and make it feel more organized. I used green and cream colors and put photos and text beside each other on larger screens, with the sections stacking on mobile.


## How I used AI
Since my Home Page and Favorites pages can be confusing to know which one you are on, I asked ChatGPT to teach me how to differentiate the two. It taught me to add the Class= "currentpage" so that when I am on one page or another, the page is highlighted. 
I asked clarifying questions on how to get my text side by side to my photo on my home page as well. 
I also got confused using Github and updating my social share after already publishing my website to Github so I used ChatGPT clarifying questions so that I could correctly publish my website.
